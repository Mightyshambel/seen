# Seen

Peer support web app — quietly matched with someone who has lived through what you're going through.

## Stack

- Vite 8 + React 19 + TypeScript
- React Router v7
- Zustand (persisted client state)
- Tailwind CSS v4
- Framer Motion
- react-hook-form + Zod

## Development

```bash
npm install
npm run dev
```

## Scripts

| Command | Description |
|---------|-------------|
| `npm run dev` | Start dev server |
| `npm run build` | Production build |
| `npm run preview` | Preview production build |
| `npm run lint` | ESLint |

## Mock auth

Any non-empty username and password on `/login` will proceed to onboarding.
